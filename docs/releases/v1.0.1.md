# PortKey v1.0.1

Fixes the macOS appearance regression in the initial 1.0.0 release package.

- Builds with macOS SDK 26 or newer so system controls adopt the native Liquid Glass appearance on macOS 26.
- Rejects older SDK builds during build and bundle verification. The minimum supported macOS version remains 13.
- No configuration reset or changes to USB/display switching policy. Existing profiles and automation preferences are preserved.
- Windows functionality is unchanged; its package carries the matching release version.

Packages: macOS arm64 and Windows x64, with SHA-256 checksums. macOS is ad-hoc signed, without Developer ID notarization; Windows is unsigned and requires the Microsoft Windows App SDK runtime. Hardware compatibility remains specific to the enrolled setup.
