# PortKey v1.0.3

Improves Mac single-controller switching from Mac to the other computer when USB inventory changes during enumeration.

- Preserves a previously established Mac ownership state for at most five seconds after the specific transient USB enumeration error. A fresh complete absent inventory, the existing 300 ms settle, and exact enrolled-display validation are still required before a remote-input command.
- Prevents a recovered inventory from being mistaken for a display reconnection that cancels the departure, and clears the resolved transient error from the interface.
- Keeps startup, sleep/wake, profile changes, other discovery errors, and missing or ambiguous displays fail closed. The Windows controller behavior is unchanged; its package carries the matching version.

Local automated validation passed 165 Rust tests, 26 synthetic DDC checks, eight simulated routes, 27 Mac presentation checks, 74 Mac state checks, strict host and Windows-target Clippy, and native Mac bundle verification. A new physical switching trial and actual sleep/wake test were not performed. This release therefore does not establish universal hardware reliability or visually confirmed improvement.

Packages: macOS arm64 and Windows x64, with SHA-256 checksums. macOS is ad-hoc signed without Developer ID notarization; Windows is unsigned and requires the Microsoft Windows App SDK runtime. Existing profiles are preserved.
