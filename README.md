# USB Follow Display

Native macOS menu-bar app that makes a Philips monitor follow a two-host UGREEN USB sharing switch.

- Mac USB ownership: HDMI1 (17).
- Windows USB ownership: DisplayPort (15).
- Trigger: the enrolled shared USB2/USB3 hub pair, not keyboard or receiver activity.

Implementation is starting. See [the current execution brief](docs/IMPLEMENTATION-BRIEF.md) and [hardware evidence](diagnostics/ddc-findings.md).
